# Library Management System

A full-featured library management application built with React, TypeScript, Convex, and Tailwind CSS.

## Tech Stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS, shadcn/ui
- **Backend:** Convex (database, auth, real-time, server functions)

## Getting Started

```sh
# Install dependencies
npm install

# Start Convex dev server (in one terminal)
npx convex dev

# Start the app (in another terminal)
npm run dev
```

## Features

- Multi-tenant institution management
- Role-based access control (Super Admin, Admin, Librarian, Student)
- Book catalog with search and filtering
- Borrowing and return workflows with penalty calculation
- Request approval system
- Book queue / waitlist
- Real-time notifications
- Library and institution CRUD
